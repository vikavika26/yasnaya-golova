# Ясная голова

Дневник головной боли, который **сам ищет триггеры**, а не просто хранит записи.
Работает как приложение на Android (PWA — устанавливается иконкой на домашний экран),
сервера нет: данные лежат в телефоне, погода подтягивается напрямую из открытого архива.

## Чем отличается от Мигребота и других дневников

Мигребот записывает и рисует календарь. Здесь дальше:

1. **Погода подтягивается сама.** По твоему городу — давление, его перепад за сутки и
   внутрисуточный размах, температура, влажность, ветер. За всю историю дневника,
   не только с момента установки.
2. **Факторы проверяются со сдвигом.** Провокатор действует за 6–48 часов, поэтому
   каждая гипотеза считается с лагом 0, 1, 2 дня. Форма кривой отличает провокатора от
   предвестника: то, что «срабатывает» только в сам день боли, скорее часть приступа.
3. **Поправка на множественные сравнения** (Беньямини — Хохберг). Если проверить двадцать
   факторов без поправки, один-два «значимых» найдутся случайно — именно так дневники
   назначают виновным сыр или шоколад.
4. **Учёт того, что дни зависимы.** После дня с болью следующий рискованнее, поэтому
   обычные тесты завышают уверенность. Выжившие гипотезы дополнительно проверяются
   блочным бутстрапом.
5. **Честное «не подтвердилось» и «данных мало».** Приложение не обязано найти триггер.
6. **Сверка убеждений с данными.** Отдельный экран: слева то, что человек сам считает
   причиной, справа — что говорят его же записи.
7. **Признаки, которые нельзя проверить, не проверяются.** Стресс и недосып в обычных
   дневниках отмечают только в дни боли — и они автоматически оказываются «виноваты».
   Приложение это распознаёт и предлагает начать отмечать их каждый день.
8. **Прогноз проверяется на будущем.** Разбиение по времени, а не случайное; отчёт о том,
   выигрывает ли модель у простого среднего.

Не медицинское устройство: диагнозов не ставит, лечение не назначает.

## Как устроено

```
pwa/                    приложение (статика, без сборки и зависимостей)
  index.html            оболочка, 4 экрана
  css/app.css
  js/stats.js           математика: RR + CI, BH, блочный бутстрап, логистика, AUC, калибровка
  js/engine.js          признаки дня, реестр гипотез, вердикты, сверка убеждений, прогноз
  js/features…          (внутри engine.js)
  js/store.js           IndexedDB: записи, погода, настройки, экспорт/импорт
  js/weather.js         Open-Meteo: архив ERA5 + прогноз, кэш в базе
  js/xlsx.js            свой минимальный читатель .xlsx (zip + SpreadsheetML)
  js/import.js          разбор выгрузки Мигребота
  js/ui.js, js/app.js   отрисовка и обработчики
  sw.js, manifest…      установка на телефон и работа офлайн
android/                обёртка для APK (Capacitor), веб-файлы кладутся внутрь при сборке
reference/              независимая реализация анализа на Python — эталон для сверки
tests/                  тесты движка, статистики и импорта (node, без зависимостей)
private-data/           личное: выгрузка Мигребота и кэш погоды. В git не попадает
.github/workflows/      сборка APK в облаке
```

Никаких библиотек и сборки: открывается как есть.

## Тесты

```bash
node tests/stats.test.mjs     # математика против известных ответов
node tests/import.test.mjs    # свой парсер xlsx против pandas, запись в запись
node tests/engine.test.mjs    # весь анализ на реальном двухлетнем дневнике
```

Смысл `reference/` — вторая, независимая реализация того же анализа. Расхождение
означает ошибку в одной из них: так был найден баг с позиционным сдвигом вместо
календарного (17 пропущенных дней в дневнике сбивали окно цикла) и баг в своём
парсере xlsx (пустая ячейка съедала две следующие).

## Как поставить на Android

Нужен https-адрес — из локального файла service worker не работает.

1. Выложить папку `pwa/` на любой статический хостинг (GitHub Pages подойдёт).
2. Открыть адрес в Chrome на телефоне.
3. Меню → «Установить приложение» / «Добавить на главный экран».
4. Открыть с домашнего экрана — запустится в полный экран, без адресной строки.
5. Вкладка «Дневник» → «Загрузить выгрузку Мигребота» → выбрать скачанный из бота `.xlsx`.
6. Погода за весь период подтянется сама; город меняется в настройках.

Проверить на компьютере перед выкладкой:

```bash
cd pwa && python -m http.server 8080     # затем http://localhost:8080
```

На `localhost` service worker разрешён, так что установка проверяется и здесь.
